# Agro Esporte Clube - Link Oficial

Landing page oficial do **Agro Esporte Clube**, desenvolvida para centralizar os principais canais digitais e links do clube em uma única página.

O projeto combina elementos visuais relacionados ao **futebol e ao agronegócio**, criando uma experiência moderna, responsiva e alinhada à identidade do clube.

---

## Sobre o projeto

O site foi desenvolvido como uma página de links personalizada para facilitar o acesso aos principais canais do Agro Esporte Clube através de um único endereço.

A página reúne:

- Compra de ingressos
- Instagram
- TikTok
- YouTube

A proposta é oferecer uma navegação simples, rápida e intuitiva, principalmente para usuários que acessam a página através das redes sociais.

---

## Funcionalidades

- Layout responsivo
- Identidade visual personalizada
- Elementos relacionados ao futebol
- Elementos relacionados ao agronegócio
- Link de ingresso em destaque
- Links para as principais redes sociais
- Animações e microinterações
- Background personalizado
- Adaptação para diferentes tamanhos e orientações de tela
- Rolagem vertical em telas com pouca altura

---

## Identidade visual

A interface foi desenvolvida com base na identidade do **Agro Esporte Clube**, combinando elementos do futebol e do agronegócio.

A composição utiliza principalmente:

- Verde escuro
- Dourado
- Tons escuros
- Elementos relacionados ao futebol
- Referências ao agronegócio
- Elementos visuais de estádio e campo
- Escudo do clube

O objetivo é transmitir uma identidade esportiva, moderna e institucional, conectando o universo do futebol à essência do Agro.

---

## Responsividade

O projeto foi desenvolvido com foco em diferentes dispositivos e proporções de tela.

Compatível com:

- Desktop
- Notebook
- Monitores de diferentes resoluções
- Smartphones em modo retrato
- Smartphones em modo paisagem

O layout se adapta ao espaço disponível, mantendo os elementos legíveis e acessíveis.
